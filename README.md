# FIREWALL
BRIEF DESCRIPTION LESS THAN 350 CHAR  4:54 AM LLM Prompt Injection Firewall is a FastAPI app that blocks malicious AI prompts using 3 layers: regex rules (fast), a fine-tuned ML transformer (subtle attacks), and embedding similarity (novel attacks). Logs all threats. Deployable via Docker. POST prompts to /v1/chat for real-time screening.
